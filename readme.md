Koishi 的 Project SEKAI 表情包绘制插件。

## 使用

`pjsk.绘制 <文本>` 绘制表情包，`/` 换行。`-n <ID>` 指定表情，缺省随机。

## 指令

| 指令 | 说明 |
| --- | --- |
| `pjsk.绘制 <文本>` | 绘制表情包 |
| `pjsk.列表.全部` | 全部表情 |
| `pjsk.列表.角色分类` | 按角色分类 |
| `pjsk.列表.展开指定角色 <角色>` | 展开角色表情 |
| `pjsk.调整` | 微调上一张图 |

常用参数：`-x` / `-y` 位置，`-r` 旋转，`-s` 字号，`-l` 行间距，`-c` 文本曲线。
